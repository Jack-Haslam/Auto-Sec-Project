# Auto-Sec-Project
The final project for my Automating Security Practices. This project was done on MFA and creating a website that compares the difference between a basic login and a login using MFA. All the work done on this project was done by me, Jack Haslam.

After the page is loaded type "python -m venv .venv" into the termainal.
Then type "source .venv/bin/activate into the terminal.
I used a virtual environment to use this application. This was done to isolate the dependencies needed for this project. To install all the libraries needed you can use the command "pip install -r requirements.txt" into the terminal.
Then type "Python3 app.py" into the terminal and click the link it provides to access the website and use the application.
